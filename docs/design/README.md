# Material de diseño

- `branding.md` y `vista-previa.html`: guía y revisión visual de los SVG finales de `public/assets/logos/`.
- `specifications/`: encargos originales, conservados como antecedentes. Sus instrucciones de estructura y video fueron sustituidas por la organización actual del [README principal](../../README.md).
- `prompts/`: instrucciones usadas para generar paisajes, personajes, cabello y nubes. Incluye variantes descartadas; un prompt no implica que el recurso siga en uso.

## Ubicación del material original

| Carpeta anterior | Ubicación actual |
| --- | --- |
| `Imagenes SVG/` | `references/branding/svg-originals/` |
| `Imagenes descargadas de WhatsApp/` | `references/branding/jpeg-originals/` |
| `Imagenes del cielo/` | `references/photos/` |
| `Imagenes diapos/` | `references/presentations/` |
| `SVG coloreados/` | SVG en `public/assets/logos/`; guía y vista previa en esta carpeta |
| `assets/` | Recursos vigentes en `public/assets/images/`; variantes en `archive/generated-images/`; prompts en `docs/design/prompts/` |

Los archivos originales y las variantes gráficas se conservaron. Los documentos históricos pueden mencionar las ubicaciones anteriores.
